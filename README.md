# -Rock-Paper-Scissors
A simple implementation of the classic Rock-Paper-Scissors game in JavaScript. The player competes against the computer over 5 rounds, and the final winner is determined by the total score.

- Interactive command-line prompts using `prompt()`
- Computer randomly selects between rock, paper, and scissors
- Keeps track of scores for both player and computer
- Declares a winner after 5 rounds
